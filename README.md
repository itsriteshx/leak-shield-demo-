## 🚀 Features

- ⚡ **Direct NPM Integration**: Imports `scanText` and `redactText` directly from `ritesh-leak-shield`.
- 🔍 **Real-Time Client-Side Scanning**: Identifies secrets with sub-millisecond latency.
- 🎭 **1-Click Auto-Redaction**: Cleans and masks detected secrets with one click.
- 🎨 **DevSecOps Cyber UI**: Modern dark theme with severity indicators and findings breakdown.

## 💻 Local Setup
